# Simple Interest Calculator

This project is a simple Python program that calculates **Simple Interest** based on the principal amount, annual interest rate, and time period entered by the user.

## Formula Used

\[
\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}
\]

## Features

- Accepts user input for principal amount, interest rate, and time period.
- Calculates simple interest using the standard formula.
- Displays the calculated simple interest.

## Requirements

- Python 3.x

## How to Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd simple-interest-calculator
   ```

3. Run the program:
   ```bash
   python simple_interest.py
   ```
